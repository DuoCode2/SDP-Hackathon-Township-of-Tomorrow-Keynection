# Glossary · 统一用语

> **给队员的中文摘要**：投影片、访谈、导览和画面要用同一套词。左栏是英文（画面和评审用），中栏是中文（团队和访谈用），右栏一句定义。同一个东西只有一个名字：例如「邻里圈」不再叫「影响圈」，「照片与维修」不再叫「证据」。

## The idea

| English | 中文 | One line |
|---|---|---|
| **Keynection** | Keynection（钥匙＋连结） | "Every key comes with five neighbours." The product; renamed from Jiran5 on 10 Oct 2026 |
| Key day / handover | 交钥匙那天 / 交屋 | The day an owner collects the keys; the welcome pack holds the join code |
| The five homes | 五户邻居 | The homes beside and opposite (terrace), or beside, above and below (apartment), worked out from the site plan |
| Neighbour circle (layer 1) | 邻里圈（第 1 层） | The five homes: names shown, direct chat |
| Layer 2 | 第二层 | Same lorong or same block: unit numbers only, contact by request |
| Layer 3 | 第三层 | The whole phase: no directory, no group; estate notices only |
| Main story | 主线 | Keys → five homes → renovation notice as the introduction → safety net → how SDP measures it |
| Safety net | 安全网 | Photo evidence, triage, warranty clock, home log: important, not the hero |

## People and roles

| English | 中文 | One line |
|---|---|---|
| Household / owner | 住户 / 屋主 | One unit, one account; the owner joins with the code |
| Family helper | 家人代办 | Up to two people the owner lets act for the household; every action carries the helper's name |
| Not on Keynection yet | 还没加入 | A unit nobody has joined for: neighbours see the unit number only; notices go on paper |
| Estate team / estate office | 物业团队 / 物业办公室 | SDP's team for the phase: concerns escalated to them, notices, the front desk |
| SDP staff | SDP 职员 | Warranty, estate, safety and front-desk roles; sign in separately in a pilot |
| Cast | 角色卡 | The demo's fictional households (Aiman, Siti, Kumar, Priya, Hafiz, Ah Hock, Sofia…) |
| Both sides | 分屏（Both sides） | Demo tool: two households side by side with the shared wall between |

## Renovation

| English | 中文 | One line |
|---|---|---|
| Renovation notice | 装修通知 | The notice the owner sends before works; it doubles as the first introduction |
| Type of work | 工程类型 | Wet work (bathroom, kitchen, pipes), hacking (walls, tiles), structural (extension), light (paint, carpentry) |
| Notice range / who is told | 通知范围 / 通知谁 | The homes a notice reaches, decided by the type of work and the plan; the owner cannot remove anyone |
| Quiet times | 安静时间 | Each household's private hours (max 2, 3 hours a day); the reason stays private |
| Noisy hours | 吵闹时段 | The hours loud work is allowed, planned around the neighbours' quiet times |
| Quiet break | 不吵的时段 | A gap inside the noisy hours that avoids a neighbour's quiet time |
| Planned around the neighbours | 先算好，不用吵 | The plain rule that sets the hours before anyone has to ask |
| Two-sided works | 两边同时施工 | A home about to get works from both sides; the owner is offered a later start |
| Paper notice | 纸本通知 | The notice printed by the front desk for a home not on Keynection |
| House rules | 屋规 | Hours contractors may enter, no works on Sundays and public holidays… |
| PBT permit | 地方政府准证 | The local council's renovation permit (national guideline in force 1 April 2026) |
| JMB / MC approval | 管理机构批准 | The apartment's management body (Strata Management Act 2013) |
| CIDB registered | CIDB 注册 | The contractor's registration with the Construction Industry Development Board; a simulated check in the prototype |

## If something goes wrong

| English | 中文 | One line |
|---|---|---|
| Pre-work photo | 开工前照片 | Sealed before the works start: fingerprinted, metadata removed |
| Follow-up photo | 跟进照片 | Taken later and compared with the pre-work photo |
| Compare / change boxed | 比对 / 标出变化 | Computer vision aligns the two and boxes what darkened (crack, stain); not machine learning |
| Case | 案件 | One pre-work photo plus one follow-up photo and what people decide about it |
| Triage | 分流 | The rule's suggestion, by time order only: before the works → warranty; after → look together; can't align → retake |
| Decision | 定案 | Building defect (owner's right), caused by the renovation (needs the other side's agreement), ask an SDP inspector, nothing to do |
| Concern | 不满 | A private complaint to the renovating neighbour (noise outside hours, dust, damage…) |
| Concern ladder | 升级阶梯 | Neighbour → renovating owner replies or fixes → estate team; every step in both home logs |
| Report | 检举 | Sending a message to SDP's safety team; the reporter stays anonymous |
| Block | 封锁 | Silent; the other side is not told |
| Warranty ticket | 保修单 | Opened for a building defect; shows the HDA clock |
| Defect liability period (DLP) | 保修期 | 24 months from handover (HDA Schedules G and H) |
| 30-day clock | 30 天时钟 | The developer's repair window after written notice; does not restart when the owner rejects a repair |
| Only the owner closes | 只有屋主能关单 | SDP submits a repair; the owner accepts or sends it back |
| Home log | 屋历 | The unit's record, one hash chain per home; only the app's own steps write to it |
| Chain checked | 链条已检查 | The server re-computed the chain and found no silent edit |
| Procore | Procore | SDP's defect-management system; tickets export to it as a punch list |

## SDP side

| English | 中文 | One line |
|---|---|---|
| Command view | 后台 / 管理画面 | SDP's screen, named after PACC (SDP's Performance Analytics and Command Centre); counts only |
| Front desk | 物业柜台 | Join codes, paper notices, renovations registered on paper, welcome packs |
| Phase setup | 新 phase 设定 | Turn a site plan into circles and notice ranges; nothing stored |
| Impact model | 影响估算 | The census question as the main metric; the cost model with labelled assumptions |
| Channels | 触达管道 | How Keynection reaches residents: step one (welcome pack, browser, WhatsApp), step two (SDP App module) |
| Safeguards | 风险与保障 | 14 risks; each measure marked Built or Pilot |
| Welcome pack / join code | 欢迎礼包 / 加入码 | A one-time QR code, valid 14 days, stored as a hash |
| Digital key | 数字钥匙 | A passkey: the phone's fingerprint, face or screen lock; pilot sign-in |
| Re-entry code | 补发码 | From the front desk after an ID check when a phone is lost; retires every old key |
| Privacy notice | 隐私声明 | Plain-language, four languages, versioned (`pilot-2026-10b`) |
